How to Upload Notes to VenkySpace

Five short steps. The one that matters most is the file name: every file is named in the same format, so we can add it to the right subject without opening it.

  1. Combine your notes into one PDF

    Scan or photograph each page, then merge them into a single PDF in page order. One PDF per topic keeps things easy to find.

  2. Name the file in the VenkySpace format

    Use Department_SemN_Subject_Type_Topic.pdf. The builder in this card writes the name for you. Copy it and rename your file.

  3. Upload the PDF to Google Drive

    Upload it to your own Google Drive and keep the file name exactly as generated.

  4. Turn on link sharing

    Right-click the file, choose Share, and under General access pick Anyone with the link as Viewer. Copy the link, then open it in a private window to check that it loads.

  5. Submit the link

    Open the Notes Vault page, use the form link there, and paste your Drive link.

File name format

Department_SemN_Subject_Type_Topic.pdf

Example

Economics_Sem1_Introductory-Microeconomics_Notes_Unit-2-Demand-Theory.pdf
  • DepartmentAs named in the vaults, e.g. Political-Science
  • SemNSem1 to Sem8
  • SubjectThe paper name from the syllabus
  • TypeNotes, Summary, Formula-Sheet, Assignment or PYQ-Solution
  • TopicUnit or chapter, or Full-Syllabus

Join the five parts with an underscore (_). Inside a part, use a hyphen (-) instead of spaces, and no other underscores.
